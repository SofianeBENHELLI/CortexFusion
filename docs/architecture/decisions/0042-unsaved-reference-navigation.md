# Préserver les saisies locales de référence

17 octobre2026, lot34. La frontière de navigation distingue désormais draft, sending et uncertain. Une saisie non enregistrée avertit avant changement de domaine/vue ou fermeture explicite ; rester reçoit le focus, Échap reste, quitter explicitement n’envoie rien. Une opération en cours continue d’interdire le départ ; un résultat inconnu conserve son propre avertissement. Le dialogue ne stocke que labels non sensibles/états, aucun texte métier.

ReferenceWorkspace enregistre sa saisie/préparation et ses reçus incertains. ReferenceReviewWorkspace enregistre motif/préparation et résultat inconnu. Naviguer entre dossiers conserve les composants et reste libre. Les lectures qui remplaceraient le motif de revue sont refusées avant HTTP ; une lecture d’historique et le pont vers la question privée conservent ce motif. Effacement local explicite par bouton/chat, impossible si préparation ou incertitude à résoudre. Les refus de droits continuent d’effacer le contenu sans choix de conservation.

Ce mécanisme ne garantit pas une sauvegarde après crash, HMR ou fermeture forcée ; beforeunload dépend du navigateur. Les autres formulaires ne sont pas requalifiés par cette tranche. Preuves dans le journal autonome, lot34.
